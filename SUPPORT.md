# Support

- **Bug reports:** use the Bug report issue form and include a minimal reproduction with reserved example domains.
- **Feature requests:** use the Feature request issue form and describe the defensive workflow it improves.
- **Security concerns:** follow [SECURITY.md](SECURITY.md); do not disclose them publicly.
- **Usage questions:** search existing issues and README documentation before opening a new issue.

This is a community-maintained project. Support is best effort; include the app version, Node.js version, operating system, and sanitized error output when relevant.
